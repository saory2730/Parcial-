HTML: El Lenguaje de Estructura
HTML (HyperText Markup Language) es el lenguaje estándar para crear páginas web. Su función principal es definir la estructura y el contenido de un sitio web utilizando etiquetas que organizan y presentan elementos como texto, imágenes y videos.

Etiquetas HTML
Una etiqueta HTML es un elemento clave que marca el inicio y el final de un componente en la página. Indican al navegador cómo debe mostrar el contenido.

Algunas etiquetas comunes son:


    <a>	Vínculo a una dirección web.	<a href="http://google.com">Google</a>
    <b>	Muestra el texto en negrita.	<b>Texto en negrita</b>
    <br>	Inserta un salto de línea.	Texto<br>en nueva línea
    <div>	Contenedor de bloque genérico.	<div>Contenido</div>
    <h1>	Encabezado de una sección (del <h1> al <h6>).	<h1>Título Principal</h1>
    <img>	Inserta una imagen.	<img src="imagen.jpg" alt="Descripción">
    <p>	Inserta un párrafo de texto.	<p>Un párrafo de texto.</p>
    <ul>	Lista desordenada.	<ul><li>Elemento</li></ul>
    <ol>	Lista ordenada.	<ol><li>Elemento</li></ol>
    <span>	Contenedor en línea.	<span>Texto en línea</span>
